# javascript-lotto-precourse

## 기능 구현 목록

- [x] 당첨 번호 입력 받기
  - [ ] 중복되지 않은 6개의 숫자, 보너스 번호 입력 받기
  - [x] 1~45 범위인지 확인
- [x] 로또 구입 금액 입력받기
  - [x] 1,000 단위로 나누어 떨어지는지 확인
  - [x] 입력값이 숫자인지 확인
  - [x] 입력값이 양수인지 확인
- [x] 구입 금액에 맞춰 발행할 로또 개수 구하기
- [x] 발행한 로또 수량에 맞춰 각 로또마다 중복되지 않는 6개의 숫자 뽑기 -[x] 숫자 출력하기
- [ ] 발행한 로또 개수에 맞춰 당첨 내역 계산하고 출력
- [ ] 수익률 계산하고 출력
