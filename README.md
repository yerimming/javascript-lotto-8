# javascript-lotto-precourse

## 기능 구현 목록

- [ ] 당첨 번호 입력 받기
  - [ ] 중복되지 않은 6개의 숫자, 보너스 번호 입력 받기
  - [ ] 1~45 범위인지 확인
- [ ] 로또 구입 금액 입력받기
  - [ ] 1,000 단위로 나누어 떨어지는지 확인
- [ ] 구입 금액에 맞춰 발행할 로또 개수 구하기
- [ ] 발행한 로또 수량에 맞춰 각 로또마다 중복되지 않는 6개의 숫자 뽑기
  - [ ] 번호의 범위가 1~45 사이인지 확인
- [ ] 발행한 로또 개수에 맞춰 당첨 내역 계산하고 출력
- [ ] 수익률 계산하고 출력
